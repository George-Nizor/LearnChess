## Stockfish isolation pattern

Stockfish is GPL-3.0. Were we to `import` it into our React tree, the GPL would propagate to our entire bundled application. We avoid this by treating Stockfish as a separate, runtime-loaded artifact:

1. **Vendored, not imported.** `stockfish-18-lite-single.js` + `.wasm` are downloaded into `public/engine/` by `scripts/vendor-engine.ts`. Vite never bundles them.
2. **Communication is over a process boundary.** The engine runs in its own Web Worker (`new Worker('/engine/stockfish-18-lite-single.js')`) and exchanges only UCI text messages with our application code via `postMessage`. No symbols cross.
3. **Source availability.** Per GPL-3.0 §6, we provide a `LICENSE.GPL` file alongside the WASM and a `STOCKFISH-SOURCES.txt` pointing to the upstream source ([github.com/nmrugg/stockfish.js](https://github.com/nmrugg/stockfish.js) and the underlying [Stockfish project](https://github.com/official-stockfish/Stockfish)).
4. **No NNUE-specific obligations.** The default network bundled with Stockfish 18 is part of the Stockfish project's GPL-3.0 release; no separate NN license applies.

This is the same pattern used by Lichess and Chess.com when embedding Stockfish on their web frontends. We are not lawyers; if you intend to commercialize this, get an actual lawyer to confirm.

### Files added at install time

```
public/engine/
├── stockfish-18-lite-single.js
├── stockfish-18-lite-single.wasm
├── LICENSE.GPL                 # verbatim GPL-3.0 text
└── STOCKFISH-SOURCES.txt       # upstream source links
```

`scripts/vendor-engine.ts` writes all four.

## Data attribution (Lichess)

All chess data we consume from Lichess is **CC0 / public domain** — no attribution is legally required. We attribute anyway as a courtesy and an act of basic professional decency.

### Puzzle dataset

- **Source:** [database.lichess.org](https://database.lichess.org/) — `lichess_db_puzzle.csv.zst`
- **License:** CC0 1.0 Universal — "research, commercial purpose, publication, anything you like."
- **Refresh cadence:** monthly. Our build script downloads the latest dump at build time.
- **Subset:** we ship a pruned, balanced ~50k-row subset; the upstream dataset is ~5.88M puzzles. Pruning algorithm and provenance manifest in `public/puzzles.manifest.json`.

### Tablebase API

- **Source:** [tablebase.lichess.ovh](https://tablebase.lichess.ovh) ([source](https://github.com/lichess-org/lila-tablebase))
- **License:** API access is free and unauthenticated. Underlying Syzygy tablebase data is generated by the [Syzygy project](https://github.com/syzygy1/tb).
- **Etiquette:** one in-flight request, 60 s back-off on 429, descriptive `User-Agent`. We cache responses by FEN.

### Opening Explorer API

- **Source:** [explorer.lichess.ovh](https://explorer.lichess.ovh) ([source](https://github.com/lichess-org/lila-openingexplorer))
- **License:** API access (when available) is free.
- **Note:** as of April 2026, anonymous access is rate-limited to effectively zero ([changelog](https://lichess.org/changelog) — DDoS mitigation). Our v1 plan does not call this API; we ship a pre-built offline opening book derived from the publicly downloadable PGN dumps instead.

### Game database (PGN dumps)

- **Source:** [database.lichess.org](https://database.lichess.org/) — monthly per-time-control PGN dumps
- **License:** CC0 1.0 Universal.
- **Use:** our build script extracts the top opening lines into a static opening book for v1 (since the live Opening Explorer API is now auth-walled).
