# LearnChess distribution notices

LearnChess application code is GPL-3.0-or-later. The full licence is in `LICENSE`.
The Windows Instrumenta launcher distributes LearnChess as a separate web application;
its own MIT licence does not replace LearnChess or third-party terms.

## Corresponding source

Each release includes `LearnChess-<version>-sources.zip` beside the installable bundle.
It contains the matching LearnChess source, lockfile, build scripts, vendored editable
artwork, Stockfish.js source/build inputs and networks, and Chessground source.
Instrumenta releases containing this build include the same source archive.
Build with Node 22.12 or later: `npm ci`, `npm run vendor:all`, `npm run build:puzzles`,
then `npm run build`. The release archive includes the vendored assets used in that
build; rebuilding does not require refreshing them. The source archive README records
revision and dependency provenance. No additional restrictions on these components apply.

## Bundled code

- Chessground 9.2.1: GPL-3.0-or-later, bundled JavaScript and CSS.
- Stockfish.js 16.0.0: GPL-3.0, separate unmodified JS/WASM worker and its NNUE networks.
  `public/engine/LICENSE.GPL` carries the full licence; `STOCKFISH-SOURCES.txt` points
  to the same-release source archive. The source archives include the complete upstream engine checkout and the locked npm network files.
- SQLite WASM: public domain, https://sqlite.org/copyright.html.
- Other bundled JavaScript dependencies retain their MIT, BSD or ISC notices.
  `scripts/write-notices.mjs` generates `dist/licenses/npm-notices.txt` from the exact
  lockfile and installed packages, and fails if a dependency notice is missing.

## Artwork, fonts and sounds

- Merida pieces: Armando Hernandez Marroquin, GPL-2.0-or-later.
- Pirouetti pieces: pirouetti, AGPL-3.0-or-later. Distributed as separate editable SVG
  artwork; its full licence and preferred source form accompany the application.
- Full upstream Lichess credits and applicable GNU licences are in `public/licenses`.
  The public package excludes Alpha and Tatiana: their non-commercial terms were
  incorrectly described as GPL in older vendor scripts. Saved selections fall back
  to CBurnett.
- Fraunces and JetBrains Mono: SIL OFL 1.1; full notices are in `public/fonts`.
- Notification sounds are original LearnChess tones generated by
  `scripts/vendor-sounds.ts`, under the project licence. No third-party recordings

- Board colour styles and LearnChess branding are project source assets.
